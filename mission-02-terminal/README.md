## 3. Commands / tools used

- pwd to show the current folder
- ls and ls -l and ls -lah to list files
- cd to change folders
- mkdir to create a folder
- echo with > and >> to write and add text to a file
- cat to show a file
- cp to copy a file
- mv to rename a file
- head with a pipe to show only the first lines
- brew --version and brew list to check Homebrew

## 4. My understanding

The Terminal lets me control files by typing commands. Flags change how a command behaves, and a pipe sends one command's output into another command. Using > replaces a file but >> adds to it. A package manager makes installing software easier and safer.
