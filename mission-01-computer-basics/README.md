## 4. My understanding

### Task 1.1 - Tracing an activity through IPOS

<!-- EDIT: replace with the activity you actually traced, if different -->

Activity traced: **writing a document and saving it to disk.**

| Stage | What happens in my example | Possible hardware / component |
|---|---|---|
| Input | I press keys on the keyboard; each keypress is sent to the computer as a signal | Keyboard |
| Processing | The word processor receives the characters, updates the document in memory and redraws the screen | CPU and RAM |
| Output | The letters appear on screen as I type | Screen (display) |
| Storage | When I save, the document is written from RAM to disk so it survives shutdown | SSD |

The activity moves through IPOS in a loop: input arrives, the CPU processes it, output
is shown, and the result is stored so it can be loaded again later. Storage feeds back
into input the next time the file is opened.

### Task 1.2 - Hardware and software

| Item / software name | Hardware or software? | Software type (if applicable) | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Enter text |
| Screen | Hardware | Not applicable | Display output |
| SSD | Hardware | Not applicable | Store files permanently |
| CPU | Hardware | Not applicable | Execute instructions |
| macOS | Software | Operating system | Manages hardware and provides services to applications |
| Brave Browser | Software | Application | Browse the web |
| VS Code | Software | Application | Write and edit code and text |
| Activity Monitor | Software | Utility | Monitor processes and resource use |

- **Operating system software** manages the computer and its resources (macOS).
- **Application software** helps the user perform tasks (browser, editor).
- **Utility software** helps maintain, protect or manage the computer (Activity Monitor).
