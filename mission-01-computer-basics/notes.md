# Mission 1 Notes

## Task 1.1 - IPOS: typing and saving a document

| Stage | What happens | Hardware / component |
|---|---|---|
| Input | I type words on the keyboard | Keyboard |
| Processing | The CPU turns each key press into a letter and keeps the document in memory | CPU and RAM |
| Output | The letters appear on the screen as I type | Screen |
| Storage | When I press save, the document is written to the disk so it stays after the laptop is turned off | SSD |

The key press goes in as input, the CPU works out what it means, the screen shows the result, and saving stores it on the SSD for later.
