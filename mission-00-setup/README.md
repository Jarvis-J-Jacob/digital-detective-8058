- git --version to check Git (version 2.55.0)
- cd to move into the project folder
- git init to start the repository
- git add and git commit to save the files
- git remote add and git push to upload to GitHub

## 4. My understanding

A repository is a project folder that Git tracks, so every change is saved and can be looked at later. GitHub stores an online copy of it. Keeping each mission in its own folder makes the work easy to find and review.
